# Replication and Extension of Card and Krueger (1994)

This repository reproduces the main empirical results of

> Card, David, and Alan B. Krueger. 1994. "Minimum Wages and Employment: A Case
> Study of the Fast-Food Industry in New Jersey and Pennsylvania." *American
> Economic Review* 84 (4): 772&ndash;793.

and adds an independent extension. The paper studies a natural experiment in
which New Jersey raised its state minimum wage from $4.25 to $5.05 per hour on
April 1, 1992, while neighboring Pennsylvania did not. Using a two-wave survey
of fast-food restaurants, the paper finds that the minimum-wage increase did not
reduce employment; if anything, employment rose in New Jersey relative to
Pennsylvania.

## What is reproduced and what is new

**Replication** (from the public Card&ndash;Krueger store-level dataset):

- Table 2 &mdash; sample means by state and wave
- Figure 1 &mdash; distribution of starting wage rates
- Table 3 &mdash; average FTE employment before and after, with difference-in-differences
- Table 4 &mdash; reduced-form regression models for the change in employment

**Extension** (not in the paper): whether New Jersey restaurants raised
full-meal prices relative to Pennsylvania after the minimum-wage increase,
estimated as a price difference-in-differences.

## Data

- **Raw data:** `input/public.csv` (410 fast-food restaurants; 331 New Jersey,
  79 Pennsylvania). This file is **not tracked in this repository** (see below).
- **Processed data:** `output/analysis_data.csv`, generated by
  `src/02_prepare_analysis.py` and read by the later scripts.
- **Column definitions:** `docs/DATA_DICTIONARY.md`.

### Obtaining and placing the raw data

The raw data is the Card&ndash;Krueger (1994) restaurant survey, distributed for
the course as package **`01_DID.zip`** (see `docs/README.md`), and publicly
available as the paper's replication dataset from David Card's data page
(<https://davidcard.berkeley.edu/data_sets.html>).

To reproduce the results:

1. Obtain the dataset `public.csv`.
2. Create an `input/` folder in the project root (if it does not exist).
3. Place the file at **`input/public.csv`**, keeping the filename exactly
   `public.csv`.

The raw data is not committed to the repository. Do not upload it to a public
repository; it is used within the applicable data-access terms.

## Reproducing the results

Requirements: Python 3 with pandas, numpy, statsmodels, matplotlib, and openpyxl.

Run the full workflow with one command, from the project root:

```bash
python src/run_all.py
```

This runs `src/01_inspect_data.py` through `src/07_extension_price_did.py` in
order, using the current Python interpreter, and stops at the first failure.
The individual scripts can also be run one at a time:

```bash
python src/01_inspect_data.py
python src/02_prepare_analysis.py
python src/03_reproduce_table2.py
python src/04_reproduce_table3.py
python src/05_reproduce_table4.py
python src/06_reproduce_figure1.py
python src/07_extension_price_did.py
```

## Known small replication differences

Two small differences from the published paper are documented in the report and
attributed to the public dataset differing slightly from the exact version used
in the paper:

1. **New Jersey $5.05 share in Wave 2.** Table 2 reports 85.5% and Figure 1
   reports 85.8% (the $5.05-centered wage bin) versus 85.2% in the paper. The
   public dataset contains one additional New Jersey store at exactly $5.05, and
   Figure 1's $0.10-wide wage bins place one store reporting $5.00 into the
   $5.05-centered bin.
2. **Table 4, model (v).** The wage-gap coefficient with region controls is 11.98
   versus 11.91 in the paper, most likely a small region-coding difference.

These differences do not change the substantive conclusions.
